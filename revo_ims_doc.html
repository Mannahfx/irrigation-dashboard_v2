1. System Overview

The Revo IMS (Irrigation Monitoring System) is an affordable, IoT-based smart agricultural monitoring and control system designed for greenhouse and small-scale farming environments. It automates the regulation of soil moisture, temperature, humidity, water flow, and tank levels while providing real-time remote access through a cloud-connected web dashboard.

Key Features

  • Real-time monitoring of 5 environmental parameters (Temperature, Humidity, Soil Moisture, Flow Rate, Tank Level)
  • Three operating modes: MANUAL, AUTO, and TIMER
  • Automated irrigation valve control based on configurable soil moisture thresholds
  • Automated cooling fan control based on temperature thresholds
  • Tank level safety interlocks to prevent pump dry-running
  • EEPROM-based offline fallback (continues operating if WiFi drops)
  • Secure MQTT communication over TLS (HiveMQ Cloud)
  • Custom React.js web dashboard with live charts, event logging, and multi-user authentication
  • 1.3" OLED display for local status monitoring
  • Water flow metering and total volume tracking

3.2 Relay Configuration

The relay module uses PC817 optocouplers and operates in Active-LOW mode:

  • digitalWrite(pin, LOW) = Relay ON (device powered)
  • digitalWrite(pin, HIGH) = Relay OFF (device unpowered)

5. Firmware Architecture

5.1 EEPROM Configuration Structure

struct SystemConfig {
  float totalLitres;   // Accumulated water flow
  float threshLow;     // Moisture % to turn valve ON (default: 10)
  float threshHigh;    // Moisture % to turn valve OFF (default: 60)
  float fanTempOn;     // Temperature to turn fan ON (default: 30°C)
  float fanTempOff;    // Temperature to turn fan OFF (default: 20°C)
  float fanHumOn;      // Humidity to turn fan ON
  float fanHumOff;     // Humidity to turn fan OFF
  uint8_t isAutoMode;  // 1 = AUTO, 0 = MANUAL
};

5.2 Operating Modes

ModeBehavior
MANUALAll actuators are controlled exclusively by the user via the web dashboard. No automatic actions are taken.
AUTOThe firmware automatically controls the irrigation valve based on soil moisture thresholds, the cooling fan based on temperature thresholds, and the pump based on tank float switch readings.
TIMERActuators are triggered based on user-configured time slots. Up to 5 timer slots can be set via the dashboard.

5.3 Auto Mode Control Logic

Irrigation Valve (Hysteresis): Valve turns ON when moisture ≤ thresholdLow. Valve turns OFF when moisture ≥ thresholdHigh. Remains in current state between thresholds to prevent chattering.

Cooling Fan: Fan turns ON when temperature ≥ fanTempOn. Fan turns OFF when temperature ≤ fanTempOff.

Tank Pump (Safety Interlock): Pump ON when FLOAT_LOW = LOW (tank empty). Pump OFF when FLOAT_HIGH = LOW (tank full). Pump BLOCKED if tank is empty to prevent dry-running.

5.4 Offline Fallback

When WiFi is lost: (1) ESP32 attempts reconnection with non-blocking 20-second timeout. (2) If reconnection fails, the system continues operating using EEPROM-stored thresholds. (3) Sensor readings, actuator control, and OLED display continue normally. (4) When WiFi returns, MQTT reconnects automatically.

9. Setup Instructions

9.1 Hardware Assembly

  1. Wire all sensors and actuators to the ESP32 according to the pin mapping table (Section 3.1)
  2. Connect the 12V power adapter to the relay module input
  3. Connect the LM2596 buck converter to 12V input, tune output to 5V
  4. Feed the 5V output to the ESP32 VIN pin
  5. Connect the OLED display to I2C pins (SDA: GPIO 21, SCL: GPIO 22)
  6. Ensure the flow sensor has an external 10kΩ pull-up resistor on GPIO 35

9.2 Firmware Upload

  1. Open esp32_firmware.ino in Arduino IDE
  2. Set your WiFi credentials (ssid, password)
  3. Set your MQTT broker credentials
  4. Set the unique Kit ID (KIT_ID)
  5. Select Board: ESP32 Dev Module with PSRAM enabled
  6. Upload to the ESP32

9.3 Web Dashboard Deployment

  1. Clone the repository
  2. Create a .env file with your MQTT and Supabase credentials
  3. Run npm install and npm run dev for local development
  4. Run npm run build and deploy dist/ to Vercel
